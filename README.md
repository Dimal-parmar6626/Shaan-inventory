# Store Inventory Management System

A complete inventory management system built with Firebase and vanilla JavaScript.

## Features

- 🔐 Firebase Authentication with role-based access
- 📦 Product management (Admin only)
- 🏷️ Category management
- 📊 Stock IN/OUT tracking
- 📈 Reports and analytics
- 💰 Indian Rupee formatting
- 📱 Fully responsive design
- 🔒 Firestore Security Rules

## Setup Instructions

1. Create a Firebase project at [Firebase Console](https://console.firebase.google.com/)
2. Enable Email/Password authentication
3. Create Firestore database
4. Update `firebase-config.js` with your Firebase configuration
5. Deploy Firestore security rules
6. Create admin user in Firebase Authentication and Firestore
